Mount `Notifier` once near the root of your app. It renders the toasts, one column per position, and the stylesheet.

```tsx
import { Notifier } from "@remcostoeten/notifier";

<Notifier position="bottom-right" tone="light" />;
```

## Behavior

- `Notifier` writes `position`, `duration` and `maxVisible` to the store before any effect in the tree runs, so toasts opened in mount effects already use them. A toast's timer starts when `Notifier` first shows it.
- Each position renders a `role="region"` labelled `Notifications`, or `labels.region`, with `aria-live="polite"`. The region of the default position is always mounted.
- Timers are also held while focus is inside a toast and while the browser tab is hidden.
- The hotkey focuses the newest open toast, and Escape dismisses the focused toast. See [Accessibility](/docs/concepts/accessibility#keyboard).
- Mounting more than one `Notifier` logs a warning in development.
- A hover or focus hold is released when its toast leaves, and when `Notifier` unmounts.

## Server rendering

`Notifier` renders its stylesheet inline and an empty region on the server. After hydration the stylesheet moves to one `<style>` element in the document head, shared with any standalone `Toast`. Toasts are client state, so none are rendered until the browser opens one.
