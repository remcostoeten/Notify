`notify.update` changes an open toast in place, so a toast can walk through states: loading, failed, retrying, done. The stylesheet changes the icon and the text at once. To animate the swap, put a component in the slot that keeps the old value on screen while it leaves. `SwapText` and `SwapIcon` are two such components. Their source is at the end of this page.

`title`, `description`, `icon.node` and the `label` of an action all take a `ReactNode`. A component in a slot stays mounted across updates, so its own state and `AnimatePresence` survive every `notify.update`.

## One step per state

A helper that builds the slots for a state keeps every call short.

```tsx
function step(status: ToastStatus, title: string, description: string): ToastInput {
  return {
    status,
    icon: { status, node: <SwapIcon status={status} /> },
    title: <SwapText>{title}</SwapText>,
    description: <SwapText>{description}</SwapText>,
  };
}
```

`status` still drives the color and the live region. `icon.node` replaces only the glyph.

<Callout type="info" title="Keep the slots the same">
  A slot that appears or disappears between states changes the height of the toast. The surface
  animates to the new height, but the text inside still jumps. Give every state a title and a
  description so only the content swaps.
</Callout>

## From a promise

The swap components stay mounted when `notify.promise` replaces the loading message, so the loading mark turns into a check.

```tsx
notify.promise(save(), {
  loading: step("loading", "Saving changes", "Writing 3 files"),
  success: step("success", "Changes saved", "3 files written"),
  error: (error) => step("error", "Could not save", error.message),
});
```

## Retry

An action keeps its button across updates, so the label can swap in place. This toast fails, stays open with `duration: 0`, and the **Retry** action opens the same toast again with `dismiss: false`.

```tsx
async function upload(fail: boolean) {
  notify({
    id: "upload",
    ...step("loading", "Uploading report.pdf", "Sending 2.4 MB"),
    actions: [{ label: <SwapText>Cancel</SwapText>, color: "muted" }],
  });

  await wait(1500);

  if (fail) {
    notify.update("upload", {
      ...step("error", "Upload failed", "The connection dropped"),
      duration: 0,
      actions: [
        {
          label: <SwapText>Retry</SwapText>,
          color: "accent",
          dismiss: false,
          onClick: () => upload(false),
        },
      ],
    });
    return;
  }

  notify.update("upload", {
    ...step("success", "Upload complete", "report.pdf is ready"),
    duration: 4000,
    actions: [{ label: <SwapText>Open</SwapText>, color: "accent" }],
  });
}
```

<SwapDemo flow="retry" />

The patch with `duration` restarts the timer, so the success toast closes four seconds after it appears.

## A fixed id

Two calls with the same `id` are two states of one toast. Repeating either call never stacks a second toast.

```tsx
function goOffline() {
  notify({
    id: "network",
    ...step("warning", "You are offline", "Changes stay on this device"),
    duration: 0,
  });
}

function goOnline() {
  notify({
    id: "network",
    ...step("success", "Back online", "Syncing 4 queued changes"),
    duration: 4000,
  });
}
```

## Stages with progress

When the icon stays the same, only the text swaps. Each stage replaces the title and the description and moves the bar, and the last update turns the spinner into a check.

```tsx
const stages = [
  { title: "Building", description: "Compiling 128 modules", progress: 20 },
  { title: "Optimizing", description: "Compressing assets", progress: 55 },
  { title: "Deploying", description: "Uploading to the edge", progress: 85 },
];

notify({ id: "deploy", ...stage(stages[0]) });
notify.update("deploy", stage(stages[1]));
notify.update("deploy", stage(stages[2]));
notify.update("deploy", {
  ...step("success", "Deployed", "Live in 12 regions"),
  progress: 100,
});
```

<SwapDemo flow="deploy" />

`stage` is `step("loading", title, description)` with `progress` added.

## Source

`SwapText` and `SwapIcon` wrap `AnimatePresence` from `motion/react`. Install `motion` if the project does not have it. The new text rises into place letter by letter, each letter starting a third of its height lower with a 2px blur. The letters start at most 160ms apart from first to last, so a one-word label and a full description finish at about the same time. The old text leaves as one piece in 120ms: it fades, moves up and blurs. The icon scales up from 0.6 on a spring with a slight bounce while its strokes draw one after another.

```tsx title="swap.tsx"
"use client";

import type { ToastStatus } from "@remcostoeten/notifier";
import { AnimatePresence, motion, useReducedMotion } from "motion/react";
import type { CSSProperties } from "react";

const ease = [0.23, 1, 0.32, 1] as const;
const pop = { type: "spring", duration: 0.45, bounce: 0.3 } as const;
const fade = { duration: 0.2, ease } as const;
const leave = { duration: 0.12, ease } as const;

const frame = {
  position: "relative",
  display: "inline-block",
  verticalAlign: "top",
} satisfies CSSProperties;

const unseen = {
  position: "absolute",
  width: 1,
  height: 1,
  overflow: "hidden",
  clipPath: "inset(50%)",
  whiteSpace: "nowrap",
} satisfies CSSProperties;

const marks = {
  success: ["m5.5 12.5 4.5 4.5 8.5-9"],
  error: ["M6.5 6.5l11 11", "M17.5 6.5l-11 11"],
  warning: [
    "m21.73 18-8-14a2 2 0 0 0-3.48 0l-8 14A2 2 0 0 0 4 21h16a2 2 0 0 0 1.73-3",
    "M12 9v4",
    "M12 17h.01",
  ],
  info: ["M12 7h.01", "M12 10.5v6.5"],
  loading: ["M21 12a9 9 0 1 1-6.219-8.56"],
} satisfies Record<ToastStatus, string[]>;

type Word = {
  text: string;
  start: number;
};

type TextProps = {
  children: string;
};

type IconProps = {
  status: ToastStatus;
};

function split(text: string) {
  let start = 0;
  return text.split(" ").map((word): Word => {
    const entry = { text: word, start };
    start += word.length + 1;
    return entry;
  });
}

export function SwapText({ children }: TextProps) {
  const reduce = useReducedMotion();
  const gap = reduce ? 0 : Math.min(0.016, 0.16 / children.length);

  return (
    <span style={frame}>
      <span style={unseen}>{children}</span>
      <AnimatePresence mode="popLayout" initial={false}>
        <motion.span
          key={children}
          aria-hidden="true"
          style={{ display: "inline-block" }}
          initial={false}
          animate={{ opacity: 1, transform: "translateY(0%)", filter: "blur(0px)" }}
          exit={{
            opacity: 0,
            transform: reduce ? "translateY(0%)" : "translateY(-25%)",
            filter: reduce ? "blur(0px)" : "blur(2px)",
            transition: leave,
          }}
        >
          {split(children).map((word, index) => (
            <span key={index}>
              {index > 0 ? " " : null}
              <span style={{ display: "inline-block", whiteSpace: "nowrap" }}>
                {Array.from(word.text).map((letter, offset) => (
                  <motion.span
                    key={offset}
                    style={{ display: "inline-block" }}
                    initial={
                      reduce
                        ? { opacity: 0 }
                        : { opacity: 0, transform: "translateY(35%)", filter: "blur(2px)" }
                    }
                    animate={{
                      opacity: 1,
                      transform: "translateY(0%)",
                      filter: "blur(0px)",
                      transition: { duration: 0.3, ease, delay: (word.start + offset) * gap },
                    }}
                  >
                    {letter}
                  </motion.span>
                ))}
              </span>
            </span>
          ))}
        </motion.span>
      </AnimatePresence>
    </span>
  );
}

export function SwapIcon({ status }: IconProps) {
  const reduce = useReducedMotion();

  return (
    <span style={frame}>
      <AnimatePresence mode="popLayout" initial={false}>
        <motion.span
          key={status}
          style={{ display: "flex" }}
          initial={{
            opacity: 0,
            transform: reduce ? "scale(1)" : "scale(0.6)",
            filter: reduce ? "blur(0px)" : "blur(4px)",
          }}
          animate={{
            opacity: 1,
            transform: "scale(1)",
            filter: "blur(0px)",
            transition: { default: pop, opacity: fade, filter: fade },
          }}
          exit={{
            opacity: 0,
            transform: reduce ? "scale(1)" : "scale(0.6)",
            filter: reduce ? "blur(0px)" : "blur(4px)",
            transition: leave,
          }}
        >
          <svg
            viewBox="0 0 24 24"
            fill="none"
            stroke="currentColor"
            strokeWidth="2"
            strokeLinecap="round"
            strokeLinejoin="round"
            aria-hidden="true"
            className={status === "loading" ? "swap-spin" : undefined}
          >
            {marks[status].map((path, index) => (
              <motion.path
                key={path}
                d={path}
                initial={reduce ? false : { pathLength: 0, opacity: 0 }}
                animate={{
                  pathLength: 1,
                  opacity: 1,
                  transition: {
                    pathLength: { duration: 0.32, ease, delay: 0.06 + index * 0.1 },
                    opacity: { duration: 0.05, delay: 0.06 + index * 0.1 },
                  },
                }}
              />
            ))}
          </svg>
        </motion.span>
      </AnimatePresence>
    </span>
  );
}
```

`popLayout` takes the leaving value out of the flow, so the toast is already the size of the new content while the old one fades. `initial={false}` skips the animation on first render, because the toast has its own entrance. It also holds back the letters and the strokes, so a new toast opens with its text and icon in place.

The letters are marked `aria-hidden` and a visually hidden copy holds the full string, so a screen reader reads the text as one phrase instead of one letter at a time.

Two rules go with the components. The first fades the tint of the status circle, which the stylesheet changes at once. The second spins the loading mark and slows it down for reduced motion. With reduced motion on, the swap keeps the opacity change and drops the movement, scale, blur, letter stagger and stroke drawing.

```css
.ntf-icon {
  transition-property: color, background-color;
  transition-duration: 200ms;
  transition-timing-function: cubic-bezier(0.23, 1, 0.32, 1);
}

.swap-spin {
  animation: swap-spin 800ms linear infinite;
}

@keyframes swap-spin {
  to {
    transform: rotate(360deg);
  }
}

@media (prefers-reduced-motion: reduce) {
  .swap-spin {
    animation-duration: 2s;
  }
}
```

Updating twice in quick succession ends on the last state with one layer on screen.
