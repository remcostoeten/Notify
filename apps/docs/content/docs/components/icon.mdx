## Usage

```tsx
<Toast.Icon status="success" />
<Toast.Icon status="warning" shape="circle" />
<Toast.Icon shape="box">
  <CloudUpload />
</Toast.Icon>
```

From `notify`, set `status`, or `icon` for control over the shape.

```tsx
notify({ status: "success", title: "Saved" });
notify({ icon: { shape: "ring", status: "warning" }, title: "Low storage" });
notify({ icon: <CloudUpload />, title: "Uploading" });
```

## Shapes

| Shape    | Description                                                  | Default for   |
| -------- | ------------------------------------------------------------ | ------------- |
| `bare`   | The glyph alone, 20px, colored by the status.                | Status toasts |
| `ring`   | Glyph with two concentric rings, 20px in the layout.         | Opt-in        |
| `box`    | 36px square with a border and a fill.                        | Custom icons  |
| `circle` | 28px circle tinted with the status color, plain mark inside. | Opt-in        |

## Coloring a custom glyph

A custom glyph inherits the text color. Use a token to match the tone.

```tsx
<CloudUpload style={{ color: "var(--ntf-accent-text)" }} />
```
