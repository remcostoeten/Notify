`Toast.Body` is the column that holds everything right of the media: the title, description, progress and actions. `Toast.Title` is the first line.

<ToastPreview example="update" trigger={false} />

## Usage

```tsx
<Toast.Body>
  <Toast.Title meta="v4.2">A new update is available</Toast.Title>
  <Toast.Description>Includes the all new dashboard view.</Toast.Description>
</Toast.Body>
```

From `notify`, set `title`, `meta` and `description`. The body is built for you:

```tsx
notify({
  title: "A new update is available",
  meta: "v4.2",
  description: "Includes the all new dashboard view.",
});
```

## Meta

`meta` adds a divider and muted text after the title, on the same line. Use it for a timestamp, a version or a source.
