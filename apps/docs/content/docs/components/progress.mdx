## Usage

```tsx
<Toast.Progress value={40} label />
<Toast.Progress value={null} />
```

From `notify`, set `progress` to a number or an object and update it with `notify.update`. See the [Progress guide](/docs/guides/progress).

## Accessibility

The bar has `role="progressbar"` with `aria-valuemin`, `aria-valuemax` and `aria-valuenow`. An indeterminate bar leaves out `aria-valuenow`. With reduced motion the fill stops animating.
