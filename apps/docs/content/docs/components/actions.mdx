`Toast.Actions` is the row under the text. `Toast.Action` is one button or link in it, in three variants and three colors.

| Variant   | Description                                               |
| --------- | --------------------------------------------------------- |
| `text`    | No padding, no border. 20px tall and flush with the text. |
| `outline` | 34px tall button with a border.                           |
| `filled`  | 34px tall button. The accent color is the primary button. |

| Color     | Text                                                         |
| --------- | ------------------------------------------------------------ |
| `default` | The strong text color.                                       |
| `muted`   | The muted text color, which turns strong on hover for text.  |
| `accent`  | The accent text color. With `filled` it is the fill instead. |

## Usage

```tsx
<Toast.Actions>
  <Toast.Action color="muted">Dismiss</Toast.Action>
  <Toast.Action variant="filled" color="accent" onClick={reply}>
    Reply
  </Toast.Action>
</Toast.Actions>
```

From `notify`:

```tsx
notify({
  title: "File moved to trash",
  actions: [{ label: "Undo", color: "accent", onClick: restore }],
});
```

## Dismissing

Pressing an action calls `onClick` with the toast handle, then dismisses the toast with the reason `action`. Pass `dismiss: false` to keep it open, for example for a retry button.

```tsx
actions: [
  {
    label: "Retry",
    dismiss: false,
    onClick: (toast) => {
      toast.update({ status: "loading", title: "Retrying" });
      retry();
    },
  },
];
```

## Links, disabled and pending

An action with an `href` renders an anchor. `disabled` dims it and ignores presses, and a disabled link drops its `href`, so Enter does not follow it either.

```tsx
actions: [{ label: "Open inbox", href: "/inbox" }];
```

`pending` is for an action whose request is in flight. It shows a spinner before the label, sets `aria-busy` and ignores presses, without the dimmed look of `disabled`. Pair it with `dismiss: false` so the toast stays open while the request runs.

```tsx
notify.update(id, {
  actions: [{ label: "Joining", variant: "filled", pending: true, dismiss: false }],
});
```

## Async actions

An `onClick` that returns a promise makes the action stateful on its own. The action turns `loading` with a spinner while the promise runs, then `success` with a check for 900ms before the toast dismisses, or `error` with a cross for 1.6s before it returns to idle and the toast stays open. `labels` gives each state its own text; a state without a label keeps the children. The label, the glyph and the width of the action crossfade between states, and a second press during a state is ignored.

```tsx
notify({
  title: "Sienna Hewitt",
  description: "Happy for us to review whenever you’re ready!",
  actions: [
    { label: "Dismiss", variant: "outline" },
    {
      label: "Reply",
      variant: "filled",
      onClick: () => sendReply(thread),
      labels: { loading: "Sending", success: "Sent", error: "Not sent" },
    },
  ],
});
```

<ToastPreview
  title="Sienna Hewitt"
  description="Happy for us to review whenever you’re ready!"
  actions={[
    { label: "Dismiss", variant: "outline" },
    {
      label: "Reply",
      variant: "filled",
      onClick: () => new Promise((resolve) => setTimeout(resolve, 1200)),
      labels: { loading: "Sending", success: "Sent" },
    },
  ]}
/>

A sync `onClick` behaves as before: the toast dismisses right after it runs unless `dismiss` is false.
