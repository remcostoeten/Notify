A 24px button in the top right corner that dismisses the toast with the reason `close`. Its touch target extends 6px past the button on every side.

## Usage

```tsx
<Toast.Close />
<Toast.Close label="Sluiten" />
```

From `notify`, `close` is `true` by default. Turn it off for one toast or for all of them:

```tsx
notify({ title: "Saved", close: false });

<Notifier close={false} />;
```
