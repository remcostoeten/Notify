## The compound API

```tsx
<Toast tone="dark">
  <Toast.Icon status="success" />
  <Toast.Body>
    <Toast.Title meta="v4.2">Details updated</Toast.Title>
    <Toast.Description>Your team can make edits.</Toast.Description>
    <Toast.Progress value={60} label />
    <Toast.Actions>
      <Toast.Action color="muted">Dismiss</Toast.Action>
      <Toast.Action>View profile</Toast.Action>
    </Toast.Actions>
  </Toast.Body>
  <Toast.Close />
</Toast>
```

Every part takes a `className`, and a class name given to `Toast` through `classNames` is applied to the matching part. See [Styling](/docs/guides/styling).
