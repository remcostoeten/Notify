<ToastPreview example="message" trigger={false} />

```tsx
<Toast.Avatar src={sienna.src} alt="Sienna Hewitt" badge="online" />
<Toast.Avatar fallback="SH" shape="circle" />
```

From `notify`:

```tsx
notify({
  avatar: { src: sienna.src, alt: "Sienna Hewitt", badge: "online" },
  title: "Sienna Hewitt",
});
```

An avatar replaces the icon. It is 40px, with an 8px radius, or round with `shape="circle"`.
